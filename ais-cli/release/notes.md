**ais 0.2.0 (GUI) & ais 0.4.4 (CLI)**

- **Desktop GUI (`ais-gui` / `ais.app`) for Windows, macOS, and Linux:** multi-pane native terminal workspace, live agent pills, usage panel, session resume, easy per-block visibility toggles, fullscreen terminal mode (`⌘⇧↵` / `Ctrl+Shift+↵`), and Ed25519-signed daily auto-updates (`--update`).
- **Terminal CLI (`ais`):** fast local session browser, search, and usage monitor for macOS, Linux, and Windows.

Install **ais** (GUI + CLI):

```sh
curl -fsSL https://ais.repentandliveholy.org/install.sh | sh      # macOS / Linux
irm https://ais.repentandliveholy.org/install.ps1 | iex          # Windows PowerShell
```

Install **ais** CLI only (headless / terminal):

```sh
curl -fsSL https://ais.repentandliveholy.org/install-cli.sh | sh  # macOS / Linux
irm https://ais.repentandliveholy.org/install-cli.ps1 | iex      # Windows PowerShell
```
